# Portfólio Pessoal – Aline Dias

**Aluna:** Aline Dias

## Descrição
Este projeto é meu portfólio pessoal, desenvolvido para apresentar meu perfil, minhas habilidades, minha formação e alguns projetos realizados durante meus estudos em Administração e Desenvolvimento de Sistemas.

## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5
- Git e GitHub
- GitHub Pages

## Link do site publicado
https://aline-dias-adm-ads.github.io/meu-portfolio/

## Funcionamento do projeto
O site é uma página única com menu de navegação. Cada item do menu direciona para uma seção: Perfil, Habilidades, Projetos, Formação e Contato. O Bootstrap é utilizado para estruturar o layout responsivo, organizar as colunas e criar o menu que funciona também em telas menores.

O arquivo `index.html` contém a estrutura e o conteúdo. O arquivo `style.css` define as cores, espaçamentos, efeitos visuais e animações.

## Recurso novo adicionado
Foi criada uma seção de Habilidades com barras de progresso animadas. Também foram incluídos efeitos de transição ao passar o mouse sobre os cartões de perfil e projetos.

## Como o recurso foi implementado
As barras foram construídas com componentes de progresso do Bootstrap. No CSS, foram definidas larguras para representar os conhecimentos em desenvolvimento e uma animação com `@keyframes` para preencher as barras ao carregar a página. Os cartões utilizam a propriedade `transition` e o efeito `:hover` para se movimentarem suavemente quando o cursor passa sobre eles.

## Publicação
O projeto deve ser publicado pelo GitHub Pages, utilizando a branch `main` e a pasta raiz (`/root`) como origem.
